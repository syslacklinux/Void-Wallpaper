# Void-Wallpaper
Taken from Void Linux 20250401

Note: This Wallpaper is not created by me because I couldn't verify the creator of that specific wallpaper maybe it was void linux contributor or something

To install it

run sudo xbps-install git

then git clone https://github.com/syslacklinux/Void-Wallpaper.git

check /usr/share/wallpapers or /usr/share/backgrounds by typing

ls /usr/share/wallpapers ls /usr/share/backgrounds

If its /usr/share/wallpapers. sudo mv /home/anon/Void-Wallpaper/void /usr/share/wallpapers (anon is example. change anon to your username)

If its /usr/share/backgrounds. sudo mv /home/anon/Void-Wallpaper/void /usr/share/backgrounds (anon is example. change anon to your username)

After moving the /home/anon/Void-Wallpaper/void to /usr/share/wallpapers or /usr/share/backgrounds move the Void-Wallpaper from /home/anon/Void-Wallpaper to trash then empty the trash

It works on Any Desktop Environment and Window Managers!
